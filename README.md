# Command Deck Collectives LLC

Complete website source and assets for the approved black-and-gold Command Deck Collectives storefront.

## Current preview

https://command-deck-collectives.mejia1604.chatgpt.site

The Sites preview is private to its owner. This repository contains the complete published build, including its source, images and hosting manifest.

## Included

- Approved photographic hero and the original crest logo, upscaled to HD (see "Logo" below).
- Five-link navigation: Shop, Services, How it works, About, Custom Orders. Search, account and cart sit in the header icons and the mobile menu.
- Five populated category blocks: real Shopify coin photograph plus apparel, awards, bulk-order and custom-project concepts.
- Three featured products. In Shopify they are "Featured product" blocks that show the live photo, title and price; the bundled photos are a fallback.
- Instagram logo links to @commanddeckllc in the desktop header, mobile menu and footer; the Shopify footer also lists the store's policy pages.
- Responsive styles, navigation and the custom-project form layout.
- A complete Shopify theme built on Dawn, plus installation instructions.
- Static deployment output in `dist/` and source preview in `preview/`.

## Project layout

- `assets/`: Command Deck styles (`command-deck.css`), JavaScript (`command-deck.js`), logo, product photos and concept imagery (WebP, sized for display), alongside Dawn's theme assets.
- `preview/index.html`: standalone page source.
- `dist/`: static Site deployment output, generated by `scripts/build-dist.sh` (copies only the assets the page uses) — do not edit by hand.
- `layout/`, `sections/`, `snippets/`, `templates/`, `config/`, `locales/`: Shopify theme source, based on [Dawn](https://github.com/Shopify/dawn) (commit `258f00f`, MIT, see `LICENSE-DAWN.md`). Dawn supplies the product, collection, cart, search, account, blog and policy pages. Command Deck files are prefixed `cd-` or named `command-deck-*` / `custom-project`: the header and footer are `sections/cd-header.liquid` and `sections/cd-footer.liquid` (loaded through `header-group.json` / `footer-group.json`), the homepage is `sections/command-deck-home.liquid`, and both custom-order forms share `snippets/cd-contact-form.liquid`.
- `.openai/hosting.json`: existing Sites identity and static output configuration.
- `docs/`: visual specifications and asset/source provenance.

To view locally, run `python3 -m http.server 8000` from the repository root and open `http://localhost:8000/preview/`. No dependency installation is required.

After changing the standalone page or assets, run `./scripts/build-dist.sh` before deploying Sites. Shopify files use Shopify asset URLs and contact-form handling; validate them with `npx @shopify/cli theme check --path .`.

## Integration status

Shopping links open the existing Shopify product pages for current pricing, availability and checkout. The standalone custom-order form remains explicitly preview-only; the Shopify Liquid form uses the store contact flow after theme installation. The live Shopify theme and domain have not been changed. See `SHOPIFY-INSTALL.md`.

## Logo

`assets/command-deck-logo.webp` (1036×920) and `command-deck-logo-518.webp` are 4× upscales of the original 259×230 crest, made with Real-ESRGAN and then color-matched back to the original so the artwork, colors and wording are unchanged. Downscaled back to 259×230 the HD file matches the original at about 32 dB PSNR. The original is kept in `docs/brand/command-deck-logo-original-259.webp`, with a lossless HD master in `docs/brand/command-deck-logo-hd-1036.png`.
